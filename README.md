# 🌸 Bloom & Blossom – Flower Ordering Website

## 📌 Project Description

Bloom & Blossom is a flower ordering website developed using HTML, CSS, and JavaScript. It allows users to explore different flower collections, search for flowers, add products to a shopping cart, manage quantities, view the total price, and fill out a delivery order form.

The website provides a simple, attractive, and user-friendly interface for online flower shopping.

## 🎯 Objectives

* To develop an attractive flower shopping website.
* To display different flower collections with images and prices.
* To provide a flower search feature.
* To allow users to add flowers to their shopping cart.
* To calculate the total price automatically.
* To provide a flower delivery order form.
* To create a responsive website for desktop and mobile devices.

## 🛠️ Technologies Used

* **HTML5** – Structures the website.
* **CSS3** – Styles the website and makes it responsive.
* **JavaScript** – Implements search, shopping cart, quantity management, price calculation, and order form interactions.
* **Visual Studio Code** – Code editor.
* **Live Server** – Runs the website locally.

## ✨ Features

### 1. Home Page

Displays the website name, introduction, and a Shop Flowers button.

### 2. Flower Collection

Displays different flowers, including:

* Rose Bouquet
* Pink Tulips
* White Lilies
* Sunflower Bunch

### 3. Search Flowers

Users can search for flowers by name.

### 4. Shopping Cart

Users can add flowers, increase or decrease quantities, and remove products.

### 5. Automatic Price Calculation

The website calculates the total price based on the selected flowers and quantities.

### 6. Order Form

Users can enter:

* Full Name
* Email Address
* Phone Number
* Delivery Address
* Delivery Date

### 7. Responsive Design

The website adjusts to different screen sizes, including desktops, tablets, and mobile phones.

## 🚀 How to Run the Project

1. Install Visual Studio Code.
2. Create a folder named `FlowerWebsite`.
3. Create `index.html`, `style.css`, and `script.js`.
4. Copy the appropriate code into each file.
5. Install the Live Server extension in VS Code.
6. Right-click `index.html`.
7. Select **Open with Live Server**.
8. The website will open in your browser.

### Local Website URL

http://127.0.0.1:5500/

**Note:** This address works on your computer while the local development server is running. It is not a public website link.

## 🛒 How to Use

1. Open the website.
2. Browse the flower collection.
3. Search for your favourite flowers.
4. Click **Add to Cart**.
5. Adjust the quantity or remove items.
6. Check the total price.
7. Click **Proceed to Order**.
8. Enter the delivery details.
9. Click **Confirm Order** to display the demo confirmation message.
